- **macOS apps now draw with Rune's native Metal backend by default.** `metal-backend` is one of Rune's default features, and an app that doesn't choose a backend draws with it, `prewarm_gpu()` included, with no restart. To keep wgpu, call `App::gpu_backend(GpuBackend::Wgpu)` (and `rune::prewarm_gpu_on(GpuBackend::Wgpu)` first in `main`), or launch with `RUNE_GPU_BACKEND=wgpu`; an app built with `default-features = false` keeps wgpu unless it adds the feature. `GpuBackend::default()` is still `Wgpu`. Pipelines made with `layout: None` now work on the native backend (it derives the layout from the shaders, as wgpu does), and a compositor that asks for a feature the backend lacks gets a wgpu device unless the app chose Metal. What the backend doesn't implement (depth and stencil, multisampling, indirect draws, render bundles, more than four colour targets, non-WGSL shaders) panics with a message naming the opt-out. wgpu's `custom` feature is now turned on for macOS alone, so Linux, Windows, web and iOS builds are unchanged. iOS keeps wgpu.
