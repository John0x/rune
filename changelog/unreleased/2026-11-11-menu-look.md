- **A `Menu` can be drawn in an app's own look and keep rune-kit's machinery.** `Menu::surface(|frame, depth| …)` draws the surface of the menu and its submenus instead of the appearance's fill, corners, border and shadow; `row_height`, `row_padding`, `row_radius`, `padding` and `highlight` set the rows' metrics and highlight; `submenu_offset(x, y)` places a submenu beside its row (`-padding` lines the first rows up); `anchor(key)` opens it by an element elsewhere in the view; `entries` adds a list of entries. `MenuItem::content(el)` draws a row's content while it keeps its role, label, shortcut, description and check for assistive tech; `MenuItem::key` keys it; `MenuItem::with(f)` adds handlers to it. `MenuEntry::Custom(el)` is any other row (swatches, a field filtering a submenu). Menus that set none of these look as before.
