- **The debug `Tx::live_only` check no longer reports a virtual list's overscan after the viewport grows.** A scroll pane that got taller without a commit (a sibling pane hid) keeps its mounted rows, since they still cover the viewport. The check's forced commit used to pick the overscan again for the new height and report the rows it built below the viewport as `added element`, though the handler changed nothing. That commit now keeps each virtual list's mounted rows, as skipping it would have, and compares every one of them, so a live-only handler that changes a row mounted below the viewport is still named. Release builds are unchanged.
