- **`rune::prewarm_gpu_on(backend)` starts the GPU prewarm on the chosen backend.** An app on `GpuBackend::Metal` called `prewarm_gpu()` before `App::gpu_backend`, so the prewarm started on wgpu and restarted on Metal. The new function chooses the backend first, then starts, and a later `App::gpu_backend` with the same backend changes nothing. `RUNE_GPU_LOG=1` now names the backend that draws, `wgpu` or `rune backend`.
